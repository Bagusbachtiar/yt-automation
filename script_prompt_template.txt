STRICT RULES:
1. Output ONLY valid JSON. No markdown code fences, no explanation text before or after, no trailing commas. The output must start with { and end with }.
2. Break the script into EXACTLY 9-12 short lines. Each line = one sentence, spoken naturally. COUNT your lines before outputting. If you have fewer than 9 lines, add more facts. Never output fewer than 9 lines.
3. FACT ACCURACY RULE: Only include claims that are well-established in scientific consensus. Do not fabricate statistics or invent specific numbers. If a quantity is uncertain, describe it qualitatively (e.g. "can travel vast distances" instead of "travels 3,000 miles").
4. CAUSAL PRECISION RULE: Do not attribute an effect to a cause unless the direct causal link is well established, with an explicit, known biological mechanism. Two true facts that appear near each other in the script are NOT automatically related. Do NOT use connective language ("this also helps", "this contributes to", "thanks to this", "because of this") to link two separate facts unless the causal connection is real and verifiable from the grounding text. EXAMPLE OF VIOLATION: "Some snakes have neurotoxic venom [true] which also helps them survive after decapitation [true but unrelated]." Venom and decapitation survival are separate facts with no shared mechanism — linking them with "also helps" fabricates a causal relationship that does not exist. Never invent a connection because two facts appear near each other.

STOCK FOOTAGE RULE: Do not name a specific species by scientific name or highly specific common name unless that species is visually distinctive and findable on stock photo sites (Pexels, Pixabay). Generic jellyfish, generic octopus, generic shrimp footage cannot stand in for a named species without being misleading. Say "this jellyfish" or "one species of jellyfish" instead of the scientific name.
6. BIOLOGY PRECISION RULE: Do not state a species-specific behavior or trait as universal across a whole genus, family, or order unless that is actually true. Use "some sharks," "most octopuses," "certain deep-sea fish" rather than blanket genus-level claims when the behavior is not universal.

Use keywords like "tuna fishing boat", "commercial fishing net", "salmon trawler", "habitat destruction". These lines are specifically about the threat — showing the threat is correct and gives the viewer visual context that matches the narration. The animal name still goes first: "tuna fishing net", "salmon bycatch boat".

8. HOMOGRAPH WARNING: Some animal names double as common non-animal words. These will pull wrong stock results unless you disambiguate:

   - "bear" with action words → teddy bears or idioms. Write "bear animal" or "brown bear".
   - General rule: if the animal name is also a common English word, add "animal", "mammal", "bird", or the animal's habitat to the keyword.

No stock photo exists for these concepts that looks right. Do NOT try to match the concept literally. Instead, use a concrete physical shot of the animal doing something related:
   - Line about echolocation → "bat flying night" not "echolocation wave diagram"
   - Line about electroreception → "platypus bill water" not "electric field underwater"
   - Line about cell biology → "[animal] close-up" not "microscope cell"
